Prețuri

Licențiere modulară: plătiți doar ceea ce cabinetul dumneavoastră folosește efectiv — și scalați oricând în sus sau în jos.

Toate prețurile sunt nete (plus TVA). Licențele se facturează lunar; modulele de instruire sunt servicii unice, la sediul clientului. Fiecare componentă este descrisă în compendiul aplicației client și în compendiul Bridge.

Încercați IRONSTICK gratuit timp de 30 de zile: descărcările și licența de probă se află pe pagina de descărcare.

2. Conturi la furnizorii de AI

Recomandat: un cont API la Anthropic (console.anthropic.com). AI-ul încorporat al IRONSTICK rulează cu o cheie API de la Anthropic, OpenAI, Qwen sau Kimi; se recomandă o cheie Anthropic, deoarece alimentează și funcții precum căutarea de linkuri web cu AI. Un cont API este un cont preplătit, pe care îl alimentați după nevoie. IRONSTICK vă alertează în aplicație de îndată ce creditul unui furnizor configurat s-a epuizat. Cu un Bridge, munca pe care o desfășurați cu AI-ul desktop rulează pe abonamentul dumneavoastră, nu pe contul API: abonamentul este taxa lunară fixă a furnizorului, în timp ce accesul API este facturat de furnizor în funcție de utilizare. Sarcinile de fundal ale aplicației client rulează pe cheile API sau, dacă sunt configurate, nivelurile gratuite Groq, OpenRouter și Mistral.

Un abonament la Anthropic, OpenAI, Qwen sau Kimi este opțional pentru IRONSTICK în sine; aplicația client singură are nevoie doar de o cheie API; Bridge-ul corespunzător funcționează prin aplicația desktop a furnizorului respectiv și prin contul dumneavoastră de acolo. Planuri de abonament: Anthropic · OpenAI · Qwen · Kimi.

Puteți încerca mai întâi aplicațiile desktop ale furnizorilor: Claude Desktop · ChatGPT Desktop · Qwen Desktop · Kimi Desktop.

3. Module de instruire

Instruirea se oferă separat, în trei module, toate susținute la sediul clientului de un trainer. În cabinetele cu unul sau doi avocați, trainerul lucrează direct pe dosarele dumneavoastră în lucru, în baza unui acord de confidențialitate; în cabinetele mai mari, instruirea începe cu sesiuni de grup și exemple lucrate.
