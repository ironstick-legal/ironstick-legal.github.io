Клиентское приложение

Рабочее место Windows

Клиентское приложение и модули Bridge работают на одном и том же компьютере Windows под одним-единственным лицензионным ключом IRONSTICK — модулям Bridge не нужен собственный ключ. Дополнительно подключается ИИ (см. «Подключение ИИ»).

IRONSTICK Client-App

Основное приложение для рабочего места: дела, клиенты, сроки, документы, работа с доказательствами и ИИ-чат — всё локально на вашем компьютере с Windows.

Bridges (MCP-Server)

Коннекторы, которые безопасно соединяют внешние ИИ-десктопы с вашим Client-App через MCP-сервер — ИИ работает непосредственно с делом. Каждый Bridge требует лицензии Client-App.

Подключение ИИ

С API-ключом ИИ в клиентском приложении доступны все функции ИИ. Суммы для активации API-ключей у разных поставщиков различаются, но составляют от 1 $ до 5 $ минимального пополнения для первоначальной активации. Рекомендуется использовать не менее двух API-ключей, чтобы повысить отказоустойчивость. Оплата в любом случае взимается по факту использования; поэтому неиспользуемые API-ключи не влекут расходов. Клиентское приложение запрограммировано так, чтобы по возможности избегать расходов и подключать API-ключи только при необходимости. После входа пользователь получает доступ через экран конфигурации и может запросить там API-ключи напрямую у поставщиков (прямые ссылки приведены).

Настольные приложения ИИ можно использовать для тестирования и без подписки. Ежемесячная стоимость подписки у поставщиков начинается примерно от 20 $ в месяц. Если вы заметите, что подписки у одного поставщика не хватает, поставщики предлагают расширения. Если подписка уже есть, её можно просто продолжать использовать с существующей конфигурацией — пользователю ничего менять не нужно. Есть два способа использовать имеющиеся настольные приложения ИИ: а) путём экспорта файлов инструкций ИИ (с большими потерями) или б) через Bridge (сервер MCP). Как только пользователь освоится со своим настольным приложением ИИ, в целях отказоустойчивости рекомендуется установить второе настольное приложение другого поставщика. Ссылки для загрузки доступны прямо на экране конфигурации.

Сервер и рабочее место сканирования

Сервер IRONSTICK — это готовый файл SPK, который устанавливается на ваш Synology NAS в 3 щелчка мышью. Всё, что вам нужно, — это Synology NAS; недорогие модели начинаются примерно от 180 €. И здесь тоже: никаких усилий по установке. Подключите и оставьте работать.

IRONSTICK Server

Работает на обычном NAS Synology и обеспечивает совместный доступ к делам, документам и срокам между несколькими рабочими местами — централизованное зашифрованное хранилище с самовосстановлением и резервными копиями. От минимум двух лицензий Client-App.

Central Scan-App

Рабочее место для оцифровки у сканера: централизованное сканирование почты и документов, привязка к делам и автоматическая загрузка. Требует наличия Server.

Порядок установки

  1. Установите первый Client-App и активируйте его лицензионным ключом.
  2. Установите Bridge(s) на том же компьютере.
  3. Установите Server на NAS (Synology).
  4. Установите Scan-App на рабочем месте сканирования.
  5. Установите и активируйте остальные Client-App.

Правила лицензирования

  • Каждая лицензия оформляется на одного пользователя (одно лицо).
  • Лицензия Server не выдаётся без как минимум двух лицензий Client-App.
  • Лицензия Scan-App не выдаётся без как минимум одной лицензии Server.
  • Лицензия Bridge не выдаётся без лицензии Client-App.

Где вводится лицензионный ключ

Client-App

Ключ вводится при запуске программы в окне лицензии (позже его можно изменить в настройках). Он одновременно активирует Bridges — им не нужен собственный ключ.

IRONSTICK Server

Ключ Server указывается при настройке Server.

Central Scan-App

Ключ вводится при запуске Scan-App в окне лицензии.

Бесплатное тестирование

Для Client-App по запросу предоставляется бесплатный лицензионный ключ на один месяц, чтобы вы могли спокойно ознакомиться с продуктом. Для Server и Scan-App тестового периода нет.

Продление лицензии

Что происходит, когда лицензия истекает? Примерно за 10 дней до окончания срока действия лицензии клиентское приложение предупреждает вас (если у вас работает сервер IRONSTICK, вы видите обзор лицензий всех подключённых клиентов). После этого вы можете очень просто заказать нужные лицензионные ключи по электронной почте или в WhatsApp. Ваш запрос проверяется по имеющимся данным, и ожидается поступление оплаты. Как только оплата поступит, вы получите новый лицензионный ключ по электронной почте / в WhatsApp. Это строка символов, которую нужно просто скопировать в ваше клиентское приложение (копировать и вставить).
