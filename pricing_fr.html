Tarifs

Licences modulaires : ne payez que ce que votre cabinet utilise réellement — et adaptez à la hausse ou à la baisse à tout moment.

Tous les prix sont hors taxes (TVA en sus). Les licences sont facturées mensuellement ; les modules de formation sont des prestations ponctuelles sur site. Chaque composant est décrit dans le compendium de l’application client et dans le compendium du Bridge.

2. Comptes chez les fournisseurs d’IA

Recommandé : un compte API Anthropic (console.anthropic.com). L’IA intégrée d’IRONSTICK fonctionne avec une clé API d’Anthropic, d’OpenAI, de Qwen ou de Kimi ; une clé Anthropic est recommandée, car elle alimente aussi des fonctions telles que la recherche de liens web par IA. Un compte API est un compte prépayé que vous rechargez selon vos besoins. IRONSTICK vous alerte dans l’application dès que le crédit d’un fournisseur configuré est épuisé. Avec un Bridge, le travail que vous effectuez avec votre IA de bureau passe par votre abonnement au lieu du compte API : un abonnement est le forfait mensuel fixe du fournisseur, tandis que l’accès API est facturé par le fournisseur à l’usage. Les tâches d’arrière-plan de l’application client utilisent les clés API ou, si elles sont configurées, les offres gratuites de Groq, OpenRouter et Mistral.

Un abonnement chez Anthropic, OpenAI, Qwen ou Kimi est facultatif pour IRONSTICK lui-même ; l’application client seule n’a besoin que d’une clé API ; le Bridge correspondant fonctionne via l’application de bureau de ce fournisseur et votre compte chez lui. Formules d’abonnement : Anthropic · OpenAI · Qwen · Kimi.

Vous pouvez d’abord essayer les applications de bureau des fournisseurs : Claude Desktop · ChatGPT Desktop · Qwen Desktop · Kimi Desktop.

3. Modules de formation

La formation est proposée séparément, en trois modules, tous dispensés sur site par un formateur. Dans les cabinets d’un ou deux avocats, le formateur travaille directement sur vos dossiers en cours, dans le cadre d’un accord de confidentialité ; dans les cabinets plus importants, la formation débute par des sessions en groupe avec des exemples traités.
