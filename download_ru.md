## Клиентское приложение

### Рабочее место Windows

Клиентское приложение и модули Bridge работают на одном и том же рабочем месте Windows под **одним лицензионным ключом IRONSTICK**. Каждый Bridge лицензируется отдельно и разблокируется в лицензионном ключе вашего клиентского приложения, поэтому отдельный ключ Bridge не нужен. Дополнительно подключается поставщик ИИ.

### IRONSTICK Клиентское приложение

Основное приложение для рабочего места: дела, клиенты, сроки, документы, работа с доказательствами и ИИ-чат — всё хранится локально на вашем рабочем месте Windows.

### Bridges (серверы MCP)

Коннекторы, которые связывают настольные приложения ИИ с вашим клиентским приложением через локальный сервер MCP, так что ИИ может работать непосредственно с делом. Каждый Bridge требует лицензии клиентского приложения.

## Подключение ИИ

![Рабочее место Windows с одной лицензией IRONSTICK, охватывающей клиентское приложение и сервер MCP, подключённое либо к API-ключу ИИ, либо к настольному приложению ИИ с подпиской.](https://www.ironstick.legal/img/dl_client.png)

С **API-ключом ИИ** в клиентском приложении доступны все функции ИИ. Рекомендуется пополнить счёт не менее чем на 20 долларов/евро у каждого поставщика. Для отказоустойчивости рекомендуется использовать не менее **двух API-ключей**. Оплата взимается по факту использования, поэтому неиспользуемый ключ ничего не стоит. Клиентское приложение разработано так, чтобы избегать расходов, и обращается к платному API только тогда, когда этого требует задача. API-ключи вводятся на экране конфигурации, где есть прямые ссылки на страницы ключей и оплаты каждого поставщика.

**Настольные приложения ИИ** можно опробовать и без подписки. Подписка — это фиксированная ежемесячная плата поставщика; если одной подписки недостаточно, поставщики предлагают расширения для дополнительной ёмкости. Имеющуюся подписку можно использовать как есть, не меняя её конфигурацию. Настольные приложения подключаются двумя способами: через Bridge (сервер MCP) или путём экспорта файлов инструкций ИИ. Как только вы освоитесь с одним настольным приложением, рекомендуется добавить приложение второго поставщика для отказоустойчивости. Ссылки для загрузки находятся на экране конфигурации.

## Сервер и рабочее место сканирования

![IRONSTICK SERVER: ваш Synology NAS плюс лицензия IRONSTICK SERVER.](https://www.ironstick.legal/img/dl_server.png)
IRONSTICK SERVER, офисный сервер, поставляется как готовый пакет Synology (SPK) и устанавливается на ваш NAS в три щелчка. Всё, что вам нужно, — обычный Synology NAS, например DS223j от примерно 180 €. После установки он работает в фоновом режиме; администрирование выполняется в браузере.

### IRONSTICK SERVER

Работает на обычном NAS Synology и связывает несколько рабочих мест: общие дела, единая библиотека нормативных актов фирмы и централизованный приём сканов на вашем собственном NAS. Он восстанавливает себя из данных рабочих мест и показывает последнюю резервную копию каждого пользователя. Сервер работает целиком внутри сети вашей фирмы — без какого-либо облака и без трафика ИИ. Доступен от двух лицензий клиентского приложения.

## Порядок установки

1. Установите первое **клиентское приложение** и активируйте его своим лицензионным ключом.
2. Установите **Bridge(s)** на том же рабочем месте.
3. Установите **IRONSTICK SERVER** на Synology NAS.
4. Установите **Central Scan App** на рабочем месте сканирования.
5. Установите и активируйте **остальные клиентские приложения**.

## Правила лицензирования

- Каждая лицензия оформляется на **одного именованного пользователя** (одно лицо).
- **Лицензия IRONSTICK SERVER** требует как минимум **двух лицензий клиентского приложения**.
- **Лицензия Central Scan App** требует как минимум **одной лицензии IRONSTICK SERVER**.
- **Лицензия Bridge** требует **лицензии клиентского приложения**; она разблокируется в ключе клиентского приложения.

## Ввод лицензионного ключа

### Клиентское приложение

Введите ключ в окне лицензии при запуске клиентского приложения; позже его можно изменить в конфигурации. Тот же ключ активирует ваши лицензированные **Bridges**; отдельного ключа Bridge нет.

### IRONSTICK SERVER

Ключ IRONSTICK SERVER вводится при настройке сервера.

### Central Scan App

Введите ключ в окне лицензии при запуске Central Scan App.
