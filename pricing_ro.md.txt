- **Module suplimentare și dependențe.** Bridge-urile și IRONSTICK SERVER sunt module suplimentare licențiate separat față de aplicația client. Fiecare Bridge se deblochează în cheia de licență a aplicației client, deci nu este nevoie de o cheie separată pentru Bridge. Central Scan App necesită o licență IRONSTICK SERVER activă (maximum 3 stații de scanare per server).
- **Bring your own AI.** AI-ul încorporat al aplicației client rulează pe cheia dumneavoastră API la furnizor — pentru aplicația client singură, o cheie API este tot ce vă trebuie. Un Bridge este diferit: funcționează prin aplicația desktop a furnizorului și prin contul dumneavoastră de acolo (de ex. Anthropic, OpenAI). Păstrați controlul deplin asupra conturilor și costurilor dumneavoastră la furnizorii de AI.
- **Scalare flexibilă.** Adăugați sau renunțați la licențe pe măsură ce se schimbă mărimea cabinetului, fără a fi nevoie să cumpărați capacitate în avans.

Încercați IRONSTICK gratuit timp de 30 de zile: descărcările și licența de probă se află pe [pagina de descărcare](https://www.ironstick.legal/download_ro.html).

## 2. Conturi la furnizorii de AI

**Recomandat: un cont API la Anthropic**
([console.anthropic.com](https://console.anthropic.com)). AI-ul încorporat al IRONSTICK rulează cu o cheie API de la Anthropic, OpenAI, Qwen sau Kimi; se recomandă o cheie Anthropic, deoarece alimentează și funcții precum căutarea de linkuri web cu AI. Un cont API este un cont preplătit, pe care îl alimentați după nevoie. IRONSTICK vă alertează în aplicație de îndată ce creditul unui furnizor configurat s-a epuizat. **Cu un Bridge, munca pe care o desfășurați cu AI-ul desktop rulează pe abonamentul dumneavoastră, nu pe contul API**: abonamentul este taxa lunară fixă a furnizorului, în timp ce accesul API este facturat de furnizor în funcție de utilizare. Sarcinile de fundal ale aplicației client rulează pe cheile API sau, dacă sunt configurate, nivelurile gratuite Groq, OpenRouter și Mistral.

**Un abonament la Anthropic, OpenAI, Qwen sau Kimi este opțional pentru IRONSTICK în sine; aplicația client singură are nevoie doar de o cheie API; Bridge-ul corespunzător funcționează prin aplicația desktop a furnizorului respectiv și prin contul dumneavoastră de acolo.** Planuri de abonament:
[Anthropic](https://claude.com/pricing) ·
[OpenAI](https://openai.com/chatgpt/pricing) ·
[Qwen](https://www.qwencloud.com/pricing/token-plan) ·
[Kimi](https://www.kimi.com/membership/pricing).

Puteți încerca mai întâi aplicațiile desktop ale furnizorilor:
[Claude Desktop](https://claude.ai/download) ·
[ChatGPT Desktop](https://openai.com/chatgpt/download) ·
[Qwen Desktop](https://chat.qwen.ai) ·
[Kimi Desktop](https://kimi.ai/).

## 3. Module de instruire

Instruirea se oferă separat, în trei module, toate susținute **la sediul clientului** de un trainer. În cabinetele cu unul sau doi avocați, trainerul lucrează direct pe dosarele dumneavoastră în lucru, în baza unui acord de confidențialitate; în cabinetele mai mari, instruirea începe cu sesiuni de grup și exemple lucrate.

| Modul | Format | Europa de Vest (net) \* | Europa de Est (net) \* |
| --- | --- | --- | --- |
| **Instruire de bază AI** | 1 zi la sediu | 2.200 € | 1.500 € |
| **Instruire expert AI** | 1 zi la sediu, extensibilă cu câte o zi | 2.500 € pe zi | 1.800 € pe zi |
| **Modul special OSINT** | la sediu, pe zile | 2.500 € pe zi | 1.800 € pe zi |

\* Plus cheltuielile de deplasare și cazare.

**Notă privind instruirea expert AI.** Se pot rezerva zile suplimentare pentru fluxuri de lucru avansate cu mai multe modele, redactare adversarială și instrucțiuni AI specifice cabinetului.
