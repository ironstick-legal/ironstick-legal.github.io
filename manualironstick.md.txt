# Manual - Client-App

> IRONSTICK user manual: every screen explained — what you see and what you can do.

Original page: https://www.ironstick.legal/manualironstick.html

---

User manual — every screen, what you see and what you can do.

## Menu bar

![The menu bar with burger menu, breadcrumb, resource display and the symbols on the right, plus the IRONSTICK browser window](https://www.ironstick.legal/img/screens/0%20menubar.png)

The menu bar that sits at the top of every screen, and the IRONSTICK browser window opened from the globe.

The menu bar sits at the top of every screen of IRONSTICK, so you can reach the important functions from anywhere.
On the left are the navigation menu and the program name, together with small live indicators. In the middle is the daily briefing. On the right are the
indicators for new e-mails, deadlines and messages, the AI chat, the browser window, the configuration and the power button. Under the bar, the breadcrumb line shows where you are.
Many symbols appear only when there is something to show. A red, animated symbol means that something new is waiting for you.

1. **Breadcrumb.** Shows the path to the current screen, for example *Main menu › Institutions*. The last part is the screen you are on. Click an earlier part to go straight back to it.
2. **Navigation menu (burger).** Opens the side menu with Main menu, Clients, Institutions, Persons, Deadlines, Tags, Texts and Search. The screen you are on is highlighted in blue. The red power symbol at the bottom of the menu closes the program, just like the power button.
3. **Resource display (Windows only).** A small bar and the text *(CPU / RAM)* show how much processor power and memory IRONSTICK itself is using. The bar is green, turns orange from 50 % and red from 80 %. Point at it to see which background tasks are running right now, with their progress and running time. Tasks that can be stopped have a red X.
4. **AI memory (pink brain).** Appears as soon as the AI has stored notes in its memory. It pulses while the AI is reading or writing the memory. Click it to check the stored notes. You can delete all notes for one client at once, or tick single notes from the latest 100 and delete them.
5. **Daily briefing (speaker).** Opens the daily briefing at any time: what is ahead today (deadlines, court dates, appointments, e-mails), what has already been done today, and a short look back. Click a line to open the matching screen, for example the deadlines, the calendar, the E-mail Monitor or the case. *Read aloud* plays the spoken version and *Stop* ends it. A switch changes the style of the spoken text only. If your last backup is more than five days old, the briefing warns you.
6. **Data Consistency Monitor.** Opens the list of suggested changes to your client and contact data that IRONSTICK found in your e-mails. For each suggestion you choose *Accept* or *Reject*. The symbol is grey when nothing is waiting and red when there are suggestions. It is also animated when a national court portal has suggested new cases (country-specific function).
7. **E-mail.** Visible only when the background e-mail check is switched on in the configuration. Grey means no new e-mails. Red and animated means new e-mails have arrived, and the tooltip shows how many. Click to open the E-mail Monitor, where everything counts as seen.
8. **AI chat (robot).** Click to open the AI chat. On Windows it opens in its own window. If you are inside a case or a client, a small violet dot shows that the chat already knows this case or client. Right-click it (or hold it on the tablet) to switch voice recognition on or off. While it is on, the robot moves and the chat listens and answers aloud. The robot is hidden while an external desktop AI is connected to IRONSTICK. On the tablet it is greyed out when there is no internet.
9. **Server chat.** Appears only when IRONSTICK SERVER — the office server — is connected. It opens a chat with the other users of the server. A green dot means the user is online and red means offline. You can delete your own messages, and a switch mutes the chat so that it no longer pops up by itself. The symbol turns red and is animated when there is an unread message.
10. **Deadline bell.** Red when at least one deadline is due today or overdue. Orange when deadlines are due in the next ten days. Grey when nothing is pending. Point at the bell to see the number. The bell is also animated when a hearing retrieved from a national court portal is scheduled for today (country-specific function). A click always opens the deadline overview.
11. **Power button.** Closes IRONSTICK immediately, without a confirmation prompt. It deletes its temporary files and browser cache and ends IRONSTICK and all processes it started.
12. **Configuration (gear).** Opens the configuration screen with the system information, storage location, user profile, AI settings, e-mail account, server connection, signature and letterhead.

### What you can do here

#### IRONSTICK browser window (globe)

- **Open the browser window.** The globe between the bell and the gear opens the IRONSTICK browser window, which has a red frame so you can always recognise it. While it is open, the globe blinks red. If the window is already open, nothing else happens.
- **Start page.** The start page explains the window, offers quick links to common social networks and shows the latest news from the IRONSTICK website, for example a new program version with its download link.
- **Let the AI chat read along.** Go to the page you want yourself, then write in the chat something like *“Look at the current browser window”*. The chat reads the page as plain text (no images) and can use it in the conversation. It can also open further pages of the same website and download files from there.
- **Logins and security checks are yours.** You do any logins and “are you human” checks yourself, in this window. The window uses its own browser profile, separate from your usual browser, so on some pages you have to log in once. These logins are kept for next time. For private browsing, use your normal browser.

#### Symbols that appear only when needed

- **Document inbox (Windows only).** A red, animated inbox symbol appears while unprocessed documents are waiting in the document inbox. The tooltip shows how many. Click it to open document capture. When nothing is waiting, the symbol disappears.
- **Notes pin (IRONSTICK SERVER).** When colleagues on the server have left new notes on a case, a red, animated pin appears. Each click takes you to the case with the next unread note and opens its pinboard.
- **AI service not available.** If an external AI service you have set up is currently unavailable, a red circle with an exclamation mark appears. Click it to see, for each service, the reason and when it will be tried again. If a service stopped because its credit has run out, *Top up* takes you straight to that service in the AI configuration.
- **Connected desktop AI (Windows only).** When an external desktop AI app works with your data, its symbol appears to the right of the resource display. It pulses while a request is running. Point at it to see which cases it has read in this session and how far, whether it has confirmed the IRONSTICK instructions, and how many rule violations it has made.

#### General behaviour

- **Move the window.** On the PC, drag any empty area of the menu bar to move the program window, just like the normal window title bar.
- **Locked during long saves.** While a long save is running, the menu bar and breadcrumb are greyed out and do not react, and you cannot go back. The screen below stays visible so you can follow the progress.
- **On the Android tablet.** The middle of the bar holds a red *DESTROY* button instead of the program name. After a confirmation it permanently deletes all IRONSTICK data from the tablet, starts the uninstall of the app and closes it. This cannot be undone. The tablet has no daily briefing and no resource display.

## 1. Main menu

![Main menu with the tabs Start, Agenda and Heatmap](https://www.ironstick.legal/img/screens/1%20menu.png)

The main menu and its three tabs: Start, Agenda and Heatmap.

The main menu is the first screen after you unlock IRONSTICK. Three tabs sit at the top:
**Start** shows what needs your attention today and opens every part of the program,
**Agenda** lists everything that happened across all your cases in date order,
and **Heatmap** shows how active your practice was over the last twelve months.

### What you can do here

#### Start tab

- **Deadlines at a glance.** The deadline card shows a green tick when nothing is overdue, together with the number of deadlines in the next 30 days. Overdue deadlines appear in red with the first entries listed. *Deadline overview* opens the full list.
- **Client birthdays.** On a client's birthday, and for two days after it, a cake appears under the deadline card. Click a name to go straight to that client.
- **Silent cases.** The second card counts the cases with no activity for 14 days and lists the first three. Click the card to see all of them, so that no case goes unattended.
- **Open any module.** Every tile opens one part of the program — clients, persons, institutions, document capture, search, calendar, daily log, word processing, E-mail Monitor, time tracking, statutes, backup and more. Each tile carries a short description of what it does.
- **Arrange the tiles your way.** Drag a tile by its handle to a new position. The order is remembered on this computer.
- **Tags and security.** The tags tile shows your coloured tags and opens the tag management. The security tile shows the state of this computer (system, drives, network) and opens the configuration.
- **Audio.** The audio tile opens the audio cutter for recordings you already have; its second link starts a live recording with AI transcription.
- **Tiles that appear only when they apply.** *Server cases* appears only when IRONSTICK SERVER is connected. Country-specific tiles appear only when those functions are switched on. A few tiles that need a PC (for example document capture and word processing) are not shown on the Android tablet.

#### Agenda tab

- **Everything in one timeline.** The feed covers three days back and ten days ahead: chronicle entries, e-mails, court dates, deadlines, pleadings, photos and transcripts from all cases. Today is shown in full; the coming and the past days are folded into one bar each. Scroll up to open the coming days one by one; click today's bar to jump back to today.
- **Every entry links onward.** The grey numbers (client / case / document) and the blue client name and green case number each open the matching screen. PDF documents show up to four page previews — click one to page through the whole document. Images open full screen with zoom; attached files open in the IRONSTICK browser window. A daily-log entry opens its full text.
- **Quick links and filters.** The bar on the left opens clients, persons, institutions, search, calendar, deadlines, daily log, E-mail Monitor and time tracking. Tick *Deadlines and court dates* to see only time-bound entries, or *Preview off* for a compact text-only list.

#### Heatmap tab

- **Key figures.** Four tiles show the activity of the last twelve months, the number of active days, the busiest day and the number of deadlines and hearings.
- **Activity calendar.** Each square is one day; the darker the green, the more happened. A red dot marks a deadline, a yellow dot a court hearing. Point at a day to see what happened (chronicle entries, pleadings, e-mails, chat, minutes worked). A click on one of the last three days opens that day in the Agenda.
- **Per client.** The drop-down narrows the whole heatmap to a single client.
- **Flared-up cases.** Below the calendar, cases that suddenly became active are listed. Click the case number to open the case, or the client name to see that client's cases.

#### Notices on start-up

- **Daily briefing.** On the first start of the day IRONSTICK asks whether you want to hear the daily briefing — a short spoken overview of your day.
- **IRONSTICK SERVER.** If the server is found but this workstation has no access to it, a notice tells you so each time the program starts; you can continue working normally.

## 2. Configuration

### System and database

![Configuration screen with the System and Database cards opened](https://www.ironstick.legal/img/screens/2%20konfig%201-2.png)

The configuration list with the System and Database cards opened.

The configuration (gear in the menu bar) collects all settings of IRONSTICK on one page, as a list of cards. Click a card's title to open it and click it again to close it. Only one card is open at a time.
The **System** card shows the details of this computer for support. The **Database** card shows how much data you hold and where it is stored on disk.
The program version and the licence key are at the bottom of the page.

#### What you can do here

**System (Windows only)**

- **Computer at a glance.** Four tiles show the processor, installed memory, graphics card and storage. Below them is the same device and Windows information that Windows shows under *Settings › System › About*. You can select every value and copy it, for example for a support request.
- **Drives.** A list shows every drive with its capacity, used space and manufacturer. Click a drive to open it in Windows Explorer.
- **Quick access to Windows.** The buttons at the bottom open the Windows settings, the Ethernet network properties, a command window that shows the full network configuration, and the volume mixer.

**Database**

- **Your data in numbers.** The card title shows the size of the database. Inside, you see the number of clients, cases, evidence entries, documents, entities, files, log entries and logins, as well as the total and free space of the drive.
- **Currently in use.** A grey box shows the folder IRONSTICK is working with right now. All data is in this one folder: database, licence, configuration and every file.
- **Change the storage location (PC).** Use *Choose folder* to pick a new location, such as a USB stick or a different drive. The *IRONSTICK* folder is created there automatically. Click *Save* to start the move. IRONSTICK first tells you how much data will be moved. It then tests the chosen drive (for example its speed, free space and write protection) and only continues if the drive passes. If you confirm, IRONSTICK closes and moves the data the next time it starts.
- **Data already at the new location.** If the chosen folder already holds IRONSTICK data, nothing is overwritten without asking. Both copies are compared, and you choose either to use the copy found there or to replace it with your current data.
- **On the Android tablet.** The data folder is fixed (it is the folder the USB synchronisation copies into), so there is nothing to choose there.

**User (PC only)**

- **Your profile.** The third card holds your details: company, function, salutation, first and last name, address, country, phone, mobile, e-mail, Facebook, date of birth, and which messaging apps you use (WhatsApp, Signal, Telegram, Viber). Click *Save* to store them. If you use IRONSTICK SERVER, your date of birth is shared with it for birthday greetings.
- **Fields taken from your licence.** With an active licence, company, salutation and name come from the licence key and cannot be changed here.
- **Your number.** Your user number is shown in brackets next to the card title. The copy symbol puts it on the clipboard, for example for a licence request.
- **Program language.** Choose the language of the program and save. IRONSTICK then reloads in the new language and returns to the main menu. An open chat window closes and opens in the new language next time.

### Desktop AI and AI configuration

![Configuration with the cards AI with local MCP server and AI configuration opened](https://www.ironstick.legal/img/screens/2%20konfig%203-4.png)

The cards for connecting a desktop AI app and for the external AI services.

These two cards control how AI works with your data. **AI with local MCP server** lets an AI app installed on this computer reach your IRONSTICK data directly. This is optional and not needed to run the program.
**AI configuration** is where you enter your access keys for the external AI services that IRONSTICK uses for its AI functions and background tasks.

#### What you can do here

**AI with local MCP server**

- **When the card appears.** The card is shown on the PC only, and only when at least one desktop AI app is part of your licence.
- **Allow access.** The first switch decides whether the connected desktop AI may access IRONSTICK at all. When it is off, the external connector cannot reach the program.
- **Allow navigation.** The second switch lets the desktop AI control the program, for example to open documents or start an export. It only works when access is allowed.
- **Set up an app.** There is one coloured *Set up …* button for each licensed desktop AI app. A click registers IRONSTICK in that app and explains the remaining steps, usually restarting the app. For Qwen Desktop, the setup text is copied to the clipboard and you paste it into the app's own settings dialog.
- **Skill plugins.** *Create IRONSTICK skill plugin* and *Create … plugin* build a skill package for the desktop AI app. A message shows where the file was saved, so you can drag it into the app.
- **Recycle desktop AI (Windows).** The light-red button closes the listed desktop AI apps and restarts them after you confirm. Use it when an app has lost its connection to IRONSTICK.
- **Links.** The links below the buttons open the download page, terms of use and privacy policy of each app in the IRONSTICK browser window.

**AI configuration**

- **Automatic order.** You do not pick one service. Every service with a stored key is used automatically, in a fixed order with the cheapest first. If a service fails, IRONSTICK passes the request to the next one. The failed service is tried again after a waiting time that depends on the error; it is skipped for the rest of the day only when its credit is used up or the cause is unknown.
- **Status badge.** The round badge in front of each service shows its place in the order. Green means available, red means currently unavailable, and grey means no key is stored. Point at a red badge to see the reason and when it will be tried again.
- **Free services for background tasks.** The services above the thick line are free offers used only for background tasks, such as e-mail prioritisation, the data monitor, the daily briefing and the situation report. Their badge shows a clock. Each has its own on/off switch, and a red caution text reminds you that your data goes to that provider. Read its terms carefully with regard to data protection (GDPR) before you switch it on.
- **Paid services.** The services below the thick line are used in the order shown. Their switch *Allow Red/Blue Team* makes the AI read a finished pleading a second time as a critical reviewer and mark anything not supported by the text. Substantial findings hold the result back. The switch can only be used once a key for that service is saved.
- **Enter a key.** Paste the access key into the key field and click *Save*. The eye symbol shows or hides the key. The order and badges update straight away.
- **Account links.** Under each service there are links to create an account and an access key, to check your balance (for some services), and to read the terms and privacy policy. They open in the IRONSTICK browser window.

### E-mail Monitor and background tasks

![Configuration with the cards E-mail Monitor and Background tasks opened](https://www.ironstick.legal/img/screens/2%20konfig%205-6.png)

The e-mail account settings and the switches for automatic background tasks.

In **E-mail Monitor** you connect your mailbox so that IRONSTICK can pick up new e-mails and assign them to your cases.
**Background tasks** collects the jobs that run automatically, with one switch each, so you decide what may run on its own and which tasks may use external AI.

#### What you can do here

**E-mail Monitor**

- **Background check.** The switch at the top turns the automatic e-mail check on or off. When it is on, mail is checked at program start and every five minutes after that, and the e-mail symbol appears in the menu bar. When it is off, neither happens.
- **Choose your mail service.** Pick your provider from the list (for example Gmail, Outlook / Hotmail, Yahoo, GMX, Web.de, T-Online, Bluewin or ProtonMail) and the server, port and encryption are filled in for you. For any other provider, choose *Other* and enter the details by hand.
- **Login.** Enter your user name or e-mail address and your password. Many providers require a separate app password. The eye symbol shows or hides it.
- **Mail URL template.** The web address used to open an e-mail in your webmail. The placeholders *{email}* and *{subject}* are filled in automatically.
- **Save and test.** *Save* stores the settings. *Test connection* logs in to your mailbox and reports either the number of messages in your inbox or the error.

**Background tasks**

- **Auto-update case descriptions (external AI).** Once a day, brings case descriptions up to date with new documents and dates. This uses external AI. By switching it on, you explicitly agree to external AI processing.
- **Auto-fetch court portal.** Fetches new case-file data and dates from the national court portal. It only retrieves data and uses no AI. This country-specific switch appears only when the country functions for Romania are active.
- **Auto-fetch e-mails.** Checks for new e-mails in the background and assigns them to cases; external AI only rates their urgency. This is the same switch as at the top of the E-mail Monitor card.

### Office server and signatures

![Configuration with the cards Office server and Signatures opened](https://www.ironstick.legal/img/screens/2%20konfig%207-8.png)

The connection to IRONSTICK SERVER and the signature field.

**Office server** connects this workstation to IRONSTICK SERVER — the office server of your firm — and shows who else is working on it.
In **Signatures** you store your handwritten signature, which IRONSTICK can place in your documents. Below these cards are the letterhead template, the login log and the version line.

#### What you can do here

**Office server**

- **Server connection.** The switch turns the connection on or off. The search for the server only runs while it is on. The status line shows whether you are connected, whether access has been requested and is waiting for approval, or whether no server was found. The rest of the card is greyed out until you are connected.
- **Server pages.** When connected, click the green status line to open the server's web page. Two buttons open the server's storage management page and the IRONSTICK SERVER administration. Each page requires its own credentials.
- **Users.** The list shows every user registered on the server. A green dot means the user is online.

**Signatures (PC only)**

- **Draw your signature.** Sign in the white field with the mouse, a pen or a finger, then click *Save*. *Clear signature field* wipes the drawing so you can start again.
- **Upload a signature.** *Upload image (JPG/PNG)* stores a scanned signature instead.
- **Stored signature.** A green tick and a small preview show the signature that is currently stored. *Delete* removes it.

**Letterhead template (PC only)**

- **Upload your letterhead.** *Upload template* takes an A4 portrait PDF with your office letterhead. In the window that opens, drag the red line (or click) to the bottom edge of the letterhead, then save. The text of your pleadings starts below this line.
- **Check and adjust.** A preview shows the stored letterhead. The switch *Letterhead on first page only* prints it on the first page only instead of on every page. *Remove template* deletes it.

**Login log and version**

- **Login log.** The last card lists the latest 50 logins, newest first: time, user number, external and internal IP address, place, country, device, operating system, browser and a security rating. You can select the text, or copy the whole table with the copy symbol.
- **Version.** The line at the bottom of the page shows the version of the Windows program and of the Android app stored in your data folder.
- **Licence key (PC).** Click *Licence key* to enter a new or renewed key and click *Activate*. If the key is invalid, expired, not yet valid or belongs to another user, you are told why. *Request licence key* prepares a ready-made request. After activation you set up your authenticator app again by scanning the QR code shown, and the licensed modules are unlocked straight away.

## 3. Clients

![Client list with search field, import and new-client buttons, a QR code window and a social media window](https://www.ironstick.legal/img/screens/3%20clients.png)

The client list, with the QR code and social media windows that open from a row.

The client list is where all your clients are kept. Each row shows the client's reference number, name, city, phone, social media, e-mail and number of cases.
From here you create new clients, import existing contacts, print the list and open a client's cases.
The picture also shows the QR code window that opens from the WhatsApp symbol, and the social media window that opens from the social symbol.

1. **Search.** Narrows the list while you type. It searches names, phone numbers and e-mail addresses; an asterisk (\*) works as a wildcard.
2. **Import client.** Imports clients from a CSV file or a vCard file.
3. **New client.** Opens an empty client form.
4. **Print list.** Creates a PDF of the whole client list, which you save to your Documents folder or into Google Drive.
5. **Client reference.** The purple number (for example *@C0000001*) is the client's reference number. Click it to copy it to the clipboard, for example to paste it into the chat or a document.
6. **Cases.** The number of cases of this client. A red cloud means at least one case is shared via IRONSTICK SERVER; a red flame means at least one case has flared up recently.
7. **Edit.** Opens the client form with this client's details.
8. **Delete.** Removes the client after a confirmation.

### What you can do here

#### Find a client

- **Search as you type.** The search checks first and last names separately and also finds names that sound alike, so small typing errors still give a result. Accents are ignored, so "Francois" also finds "François".
- **Phone and e-mail.** Type part of a phone number (spaces and dashes do not matter) or part of an e-mail address. If you type several words, a client must match all of them.
- **Clear the search.** The small X in the search field shows the full list again. If nothing matches, the list says so.
- **Most urgent first.** Clients with a flared-up case are at the top, then clients with the most cases, then those with the most recent activity, then alphabetically.
- **Several pages.** With more than 25 clients the list is split into pages; page navigation then appears above and below the list.
- **Birthdays.** On a client's birthday, and for two days after it, a small cake appears in front of the name. If you came here by clicking a birthday name in the main menu, the list shows only the clients who have a birthday right now.

#### Work with a client row

- **Open the cases.** Click anywhere on a row to open that client's case list.
- **Call, WhatsApp or e-mail by QR code.** Click the phone number, the green WhatsApp symbol or the e-mail address. A window shows a QR code that you can scan with your phone to call, open WhatsApp or write an e-mail. A click on the QR code opens the matching program on this computer; if there is none, the value is copied to the clipboard.
- **Social media.** The blue symbol in the *Social* column appears only when profiles are recorded. It opens a window listing Facebook, Instagram, TikTok, LinkedIn and X profiles. The open symbol shows the profile in the IRONSTICK browser window (on the tablet: in the system browser); the copy button copies the address.
- **Copy the reference number.** A click on the purple *@C* number copies it, for example to paste it into a chat or a document.
- **Delete a client.** The X opens a confirmation. If the client still has cases, documents or case links, a yellow warning lists them before you confirm. Notes that the AI has remembered about this client are removed as well.

#### Print the client list

- **PDF of all clients.** The print button in the card header creates a client list as PDF. In the export window you can save it to your Documents folder, or into a Google Drive folder if Google Drive is installed on this computer.

#### Create or edit a client

- **Master data.** Name (required), personal identification number, nationality, language and birthday. Choosing a nationality also pre-selects the matching language. The birthday is picked from a calendar and can be cleared with the X.
- **Address.** Street, postcode, district/county, city and country.
- **Geo-coordinates.** Turn on the switch to place the client on a map. IRONSTICK looks up the address automatically; you can correct the search text and search again, type latitude and longitude yourself, or simply click the map to set the point.
- **Contact.** Phone (tick *WhatsApp* if the number uses WhatsApp), e-mail and a free text field for details. An invalid e-mail address is reported before saving.
- **Bank details and social media.** Bank name and IBAN; addresses of the Facebook, Instagram, TikTok, LinkedIn and X profiles.
- **Save or cancel.** The buttons at the bottom save the client or leave the form without changes. When editing, the client number and the creation date are shown under the title.

#### Import clients

- **Drop a file.** *Import client* opens a window with a drop area. Drag a CSV file or a vCard file (for example exported from your phone or mail program) onto it.
- **Assign columns (CSV only).** A second window lists every column of the file with a sample value and the field it will go into. The assignment is pre-filled; change any field with the drop-down or choose not to import a column. *Continue* becomes available once one column is assigned to the name.
- **One contact.** If the file contains a single address, the *New client* form opens already filled in, so you can check, complete and save it yourself.
- **Several contacts.** You get a list with a tick box for each contact; all are ticked in advance. Contacts that already exist as clients are not ticked and are marked as already present. *Import* creates all ticked clients in one step and shows how many were added.
- **When something goes wrong.** If the file cannot be read or contains no address, the window tells you. If the import fails, nothing is changed.

## 4. Cases

### The case list of a client

![Case list of a client grouped into matters, with the nucleu window and the snakes window of a matter](https://www.ironstick.legal/img/screens/4%20cases.png)

A client's cases, grouped into matters, with the nucleu and snakes windows of a matter.

This screen shows all cases of one client. Cases that belong together are grouped into **matters** (for example all proceedings against the same opponent); cases not yet placed in a matter appear under *Unassigned cases*.
You can create matters, sort cases into them by drag and drop, and see each case's priority, status and chances of success at a glance.
The picture also shows the nucleu window and the snakes window that open from the two symbols in a matter's title bar.

1. **Notes.** Opens the notes board for this client.
2. **Print.** Creates a PDF overview of all this client's cases, with or without an AI summary of the latest status.
3. **New matter.** Creates a new group for cases that belong together.
4. **Universe.** Shows the client's cases as a network, as a 3D map or a 2D map. Available once the client has three or more cases.
5. **New case.** Opens the form for a new case of this client.
6. **Matter.** The title bar of a matter. Click it to fold or unfold the matter. The two symbols in the middle open the nucleu and the snakes of the matter; on the right you see the number of cases, rename (pencil) and delete (X).
7. **Nucleu of the matter.** A general AI instruction that applies to every case of this matter. Write here what every document written for these cases must take into account, then save.
8. **Snakes of the matter.** The snakes of all cases in this matter, in list order. Click a case to open it on its snake tab.
9. **Drag handle.** Grab the dotted handle and drag the case into a matter, or drop it onto an existing case to make it a sub-case of that case.
10. **Remove from matter.** Takes the case out of this matter. The case itself is kept and appears under *Unassigned cases* unless it is also in another matter.
11. **Chances of success.** A small gauge showing the result of the latest AI assessment of the case. Point at it to read the percentage; click it to open the case on the assessment tab.

#### What you can do here

**Read a case row**

- **Open a case.** Click a row to open the case on its Timeline tab.
- **Numbers and tags.** Each row starts with the client/case number, followed by blue tags for country, area of law and procedural stage. Point at a tag to see its full name.

A case can additionally have its own nucleu, set in the case itself. If you close the window with unsaved changes, IRONSTICK asks whether to discard them.
- **Snakes.** The snake symbol opens the snakes of all cases in the matter. A snake records the statements of the opposing side that are contradicted by documents, with the place where each was found and the documents that contradict it. Click a case title to open that case on its snake tab. If no case has a snake yet, the window says so.

**Print, new case and more**

- **Case overview as PDF.** The print button asks whether you want the overview with or without the latest status written by the AI. If you choose the AI version and it uses external AI, you are asked for consent first. The PDF is then saved to your Documents folder or to Google Drive.

- **Other clients in the same proceeding.** If you have further clients, you can search them by name or *@C* number and add them to the case. The case then also appears in their case lists.
- **Conflict of interest check.** As soon as your own side and the opponent are filled in, this button compares the names with your own clients, parties and cases and shows the result. Nothing leaves this computer.
- **Further options.** Mark a case as public (reported in the media), or lock it so that no other case can be linked to it, whether by hand, automatically or by the AI.
- **Legal details.** Entering a court case number ticks *has a case number* and sets today's date, which you can change. Choose the country first; the areas of law and procedural stages for that country are then offered. A free description field completes the form.
- **Subscribed cases.** When IRONSTICK SERVER is connected and you follow cases of a colleague, they appear in their own card with a blue cloud, the owner's name and the owner's last change. Click one to open it.
- **No cases yet.** A client without cases shows a short notice with a *New case* button.

### How the AI assessment is made

![AI assessment with the sections fed by the whole case file marked green and the court-file section with the prospects gauge marked red](https://www.ironstick.legal/img/screens/5%20case%20assesment%20detail.png)

Green: drawn from the whole case file. Red: only the part of the file that the court has.

The assessment works with two different sources, marked in the picture.
The **green** sections are written from the whole file in IRONSTICK — every document, entry, e-mail and transcript of the case — and from the neighbouring cases of the same client.
The **red** section with the gauge judges only the part of the file that lies before the court: what you submitted to it and what it or the other side sent to you. Documents the court has never seen do not count towards the prospects of success.

#### What you can do here

**The green sections — your whole file**

- **Basis of the proceedings.** Who claims what against whom, before which court or authority, as it follows from the whole file.
- **State of the IRONSTICK file.** The complete picture of the case as it stands in IRONSTICK, including your own notes, evidence and correspondence that the court does not know about, and the effects of the client's other cases.
- **Critical note, strengths and risks.** Also written from the whole file and the neighbouring cases.

**The red section — only the court file**

- **State of the court file.** Describes only what the court has on its file — every submission and every document received from the court or the other side in these proceedings.
- **Prospects of success.** The gauge runs from red (lost) at the bottom to green (won) at the top; the arrow and the percentage show the AI's estimate, and the verdict below it (for example *rather won*) puts it into words. Where available, separate figures follow for the state of the evidence, the main claim and the other claims.
- **Why only the court file.** The court decides on what it has in front of it. A strong document in your file that was never submitted does not improve the estimate until it reaches the court — the green sections show you such gaps.
- **No court file, no estimate.** If IRONSTICK cannot identify the court or the documents before it, the red section is missing and the gauge stays empty.

### How a document travels through capture

![Diagram: PDF, page selection, local processing, external AI on the internet, capture form, AES-256 encryption, database and stamped PDF](https://www.ironstick.legal/img/screens/8%20capture%20documents%20proces.png)

From the PDF in the inbox to the encrypted entry in the case.

The diagram shows the path of a document from left to right. The PDF is first processed on your computer (page selection and text reading),
then only the text goes to the external AI over the internet for classification, and the result comes back into the capture form.
After you save, the document is encrypted with AES-256 and stored as an entry in the database together with the stamped PDF.

#### What you can do here

- **Step 1 — on your computer.** You choose the pages; IRONSTICK reads their text and recognises known parties and the case without any internet connection.
- **Step 2 — external AI, only with consent.** The extracted text is sent to the external AI to suggest the classification. Nothing is sent before you agree, and you can always fill in the form yourself.
- **Step 3 — your check.** You review and correct every suggestion in the capture form; only what you save is stored.

### What you can do here

#### Adding statutes

- **By link or file.** In the *Create* window, enter a web address or drop PDF/MD files; dropped files are listed and can be removed with the small cross. A link that already exists in the library is not added twice; an invalid link shows *Failed*.
- **Fetched in the background.** While a statute is being prepared, a progress bar shows the stage it has reached. If loading was interrupted, click the bar to start it again. The list updates on its own when the statute is ready.
- **Proposed by the AI.** When the AI finds a statute that is missing from the library, it does not add it silently. You get a window listing the proposals and tick the ones you want to keep.

#### The list

- **Each entry.** Title, date added, legal area and a short description, the source link, and labels for the country and the type of act (law, ordinance, decision …). Click the source link to open the original page in the IRONSTICK browser window. Statutes you uploaded as a file show the file name instead of a link.
- **Red entries at the top.** A statute shown in red could not be loaded, or has not been re-checked for more than a month. Click a failed entry to try loading it again.
- **Greyed-out entries.** A statute whose source can no longer be verified is greyed out and labelled *not verifiable*. Click that label to open the source in the IRONSTICK browser window and check it yourself; the opened text then shows a red notice at the top.
- **Acceptance pending.** A newly prepared statute waits for your confirmation in the data monitor. Click the label to go there. Only accepted statutes are shared via IRONSTICK SERVER.
- **Delete.** The bin icon removes one of your own statutes after a confirmation. If IRONSTICK SERVER is connected, the statute is removed there too.
- **Pages.** With more than 20 statutes, page navigation appears above and below the list.

#### Filters

- **All, Own, Others.** *Own* shows the statutes you added; *Others* shows statutes that other users added via IRONSTICK SERVER. Those carry their owner's ID and name under the title and cannot be deleted by you.
- **Expired.** Shows only the statutes whose source can no longer be verified.
- **Country.** The drop-down next to the filters limits the list to one country.

#### Searching

- **Across the whole library.** The search ignores accents and special letters and also finds words that begin with your search term; article numbers are matched exactly. On the results screen, click a statute's title to open it at the first place found, or click an excerpt to jump straight to that place.
- **Within one statute.** In the opened statute, type a term and press Enter or *Search*. All places found are marked in yellow and the text jumps to the first one. Click the counter (for example *1/12*) to move to the next place; after the last one it starts again from the first.

## 17. Server cases

![Server cases with the card My shared cases and its subscribers](https://www.ironstick.legal/img/screens/17%20server%20cases.png)

Cases you share via IRONSTICK SERVER, with their subscribers.

Server cases is where you work with cases that are shared between users of IRONSTICK SERVER — the office server.
You see which of your own cases you have shared and who follows them, and you can subscribe to cases that other users share.
This screen, and its tile in the main menu, appear only when the server is connected. The picture shows one shared case with two subscribers.

### What you can do here

#### Incoming handovers

- **Take over a case.** When another user hands a case over to you, it appears in this card at the very top. Click *Import* to bring it into your own data.
- **Checked import.** The case package is downloaded and checked for completeness first. You then choose whether the client already exists with you or is added as a new client. If you already have a case with the same number, you are offered to merge the two. Where the data differ, a list of the differences is shown, and at the end a message confirms how many entries and files were imported.

#### My shared cases

- **Your shared cases.** Lists every case you have shared from the case screen, with case number and client. Click the case to open it.
- **Remove sharing.** Ends the sharing of this case on the server.
- **Subscribers.** The users following the case are listed below it. A user who has asked to follow is marked *Requested*; click *Accept* to let them in. *Remove* ends an active subscription or turns down a request. If nobody follows the case yet, the card says so.

#### Cases shared by others

- **The list.** Shows the cases other users have shared with everyone or with you personally, with case, owner and office. If there are none, the card shows *No entries available*.
- **Request subscription.** For a case shared with everyone, you ask the owner to let you follow it. The label *Requested* appears until the owner accepts.
- **Subscribe.** For a case shared with you personally, the subscription is active immediately; the label changes to *Subscribed*.
- **Unsubscribe.** Ends your subscription or withdraws your request.
- **Server not reachable.** If the connection to the server is lost, the card shows that no server is connected.

## 18. Backup

![Backup screen with data backup, recent backups and restore](https://www.ironstick.legal/img/screens/18%20backup.png)

Create a data backup, see the recent backups, or restore one.

The backup screen saves all your case data into a single ZIP file, and puts it back when you need it.
You decide where the file goes — a local folder, an external SSD or a USB stick.
The database and the stored case files keep their AES-256 encryption inside the backup. The picture shows the backup card, the list of recent backups and the restore card.

### What you can do here

#### Back up

- **Create data backup.** Saves your database, your documents and files, and your configuration and licence into one ZIP file. Language models for the local AI and voice output are left out, because they can be downloaded again.
- **Progress.** A window shows how far the backup has got (file X of Y) and which file is being packed. The backup runs in a separate background process, so you can keep working.
- **Choose where to save.** When the ZIP is ready, a save dialog asks for the location and file name. If you cancel, no file is kept. When saving has finished, a message shows the file name, size and number of files.
- **Recent backups.** The last five backups are listed with date and time, file name and size, so you can see at a glance when you last backed up.
- **From the chat.** If you ask the chat to make a backup, this screen opens and starts the data backup straight away.
- **IRONSTICK SERVER.** When the server is connected, every backup and every restore is reported to it: **who** made it, **when**, from which IP address, the type, file name and size — never the backup data itself. The administrator sees this on a page of the server, together with each user's last backup date (shown in red after more than five days), and can remind users to back up.

#### Restore

- **Choose backup.** Select a backup ZIP. IRONSTICK first checks that it really is an IRONSTICK backup; any other file is refused with a notice.
- **Confirm.** Restoring overwrites your current data. A window asks you to confirm; click *Cancel* to stop, or *Restore* to go ahead.
- **Progress and result.** A progress window shows each file as it is put back, and a message tells you whether the restore succeeded. Because the backup contains your configuration and licence, these are restored as well.
