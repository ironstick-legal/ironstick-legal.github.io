Pricing

Modular licensing: pay only for what your law firm actually uses — and scale up or down at any time.

All prices are net (plus VAT). Licences are billed monthly; training modules are one-off on-site services. Each component is described in the Client App compendium and the Bridge compendium.

2. AI provider accounts

Recommended: an Anthropic API account (console.anthropic.com). The built-in AI of IRONSTICK runs on an API key from Anthropic, OpenAI, Qwen or Kimi; an Anthropic key is recommended because it also powers functions such as the AI web link search. An API account is a prepaid credit account that you top up as needed. IRONSTICK alerts you in the app as soon as a configured provider's credit is used up. With a Bridge, the work you do with your desktop AI runs on your subscription instead of the API account: a subscription is the provider's flat monthly fee, while API access is billed by the provider per use. Background tasks of the Client App run on the API keys or, if set up, the free tiers of Groq, OpenRouter and Mistral.

A subscription with Anthropic, OpenAI, Qwen or Kimi is optional for IRONSTICK itself; the Client App alone needs only an API key; the corresponding Bridge works through that provider’s desktop app and your account there. Subscription plans: Anthropic · OpenAI · Qwen · Kimi.

You can try the providers' desktop apps first: Claude Desktop · ChatGPT Desktop · Qwen Desktop · Kimi Desktop.

3. Training modules

Training is offered separately in three modules, all delivered on site by a trainer. In firms with one or two lawyers, the trainer works directly on your live case files under a non-disclosure agreement; in larger firms, training starts with group sessions and worked examples.
