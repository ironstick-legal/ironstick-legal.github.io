Licencias modulares: pague solo lo que su despacho utiliza realmente — y amplíe o reduzca en cualquier momento.

2. Cuentas con proveedores de IA

Recomendado para usar IRONSTICK: una cuenta API en Anthropic (console.anthropic.com). Funciona como una cuenta de saldo prepago que usted recarga según sus necesidades, y sostiene las funciones de IA básicas de IRONSTICK. IRONSTICK muestra un aviso visible en la app en cuanto se agota el saldo de un proveedor configurado. Con los Bridges, estos costes de API bajan considerablemente — todas las consultas costosas pasan entonces por la suscripción en lugar de por la cuenta API.

Las suscripciones con Anthropic, OpenAI, Qwen y Kimi son opcionales para usar IRONSTICK — pero pasan a ser obligatorias para usar el Bridge correspondiente. Planes de suscripción: Anthropic · OpenAI · Qwen · Kimi.

Puede probar las apps de escritorio desde ya — descargas: Claude Desktop · ChatGPT Desktop · Qwen Desktop · Kimi Desktop.
