# Tarifs

> Tarifs IRONSTICK : licences mensuelles modulaires pour l’application client, les Bridges d’IA de bureau et le serveur de cabinet, ainsi que des modules de formation sur site. Tous les prix hors taxes.

Page d’origine: https://www.ironstick.legal/pricing_fr.html

---

Licences modulaires : ne payez que ce que votre cabinet utilise réellement — et adaptez à la hausse ou à la baisse à tout moment.

Tous les prix sont **hors taxes** (TVA en sus). Les licences sont facturées mensuellement ; les modules de formation sont des prestations ponctuelles sur site. Chaque composant est décrit dans le [compendium de l’application client](https://www.ironstick.legal/kompendium_fr.html) et dans le [compendium du Bridge](https://www.ironstick.legal/bridge_fr.html).

- **Modules complémentaires et dépendances.** Les Bridges et IRONSTICK SERVER sont des modules complémentaires de l’application client, sous licence séparée. Chaque Bridge est débloqué dans la clé de licence de votre application client : aucune clé Bridge distincte n’est donc nécessaire. La Central Scan App nécessite une licence IRONSTICK SERVER active (3 postes de numérisation maximum par serveur).
- **Apportez votre propre IA.** L’IA intégrée de l’application client fonctionne avec votre clé API chez le fournisseur : pour l’application client seule, une clé API suffit. Un Bridge, c’est différent : il fonctionne via l’application de bureau du fournisseur et votre compte chez ce fournisseur (p. ex. Anthropic, OpenAI). Vous gardez le contrôle total de vos comptes et de vos coûts chez les fournisseurs d’IA.
- **Échelle flexible.** Ajoutez ou résiliez des licences selon l’évolution de la taille de votre cabinet, sans devoir acheter de capacité à l’avance.

Essayez IRONSTICK gratuitement pendant 30 jours : les téléchargements et la licence d’essai se trouvent sur la [page de téléchargement](https://www.ironstick.legal/download_fr.html).

## 2. Comptes chez les fournisseurs d’IA

**Recommandé : un compte API Anthropic**
([console.anthropic.com](https://console.anthropic.com)). L’IA intégrée d’IRONSTICK fonctionne avec une clé API d’Anthropic, d’OpenAI, de Qwen ou de Kimi ; une clé Anthropic est recommandée, car elle alimente aussi des fonctions telles que la recherche de liens web par IA. Un compte API est un compte prépayé que vous rechargez selon vos besoins. IRONSTICK vous alerte dans l’application dès que le crédit d’un fournisseur configuré est épuisé. **Avec un Bridge, le travail que vous effectuez avec votre IA de bureau passe par votre abonnement au lieu du compte API** : un abonnement est le forfait mensuel fixe du fournisseur, tandis que l’accès API est facturé par le fournisseur à l’usage. Les tâches d’arrière-plan de l’application client utilisent les clés API ou, si elles sont configurées, les offres gratuites de Groq, OpenRouter et Mistral.

**Un abonnement chez Anthropic, OpenAI, Qwen ou Kimi est facultatif pour IRONSTICK lui-même ; l’application client seule n’a besoin que d’une clé API ; le Bridge correspondant fonctionne via l’application de bureau de ce fournisseur et votre compte chez lui.** Formules d’abonnement :
[Anthropic](https://claude.com/pricing) ·
[OpenAI](https://openai.com/chatgpt/pricing) ·
[Qwen](https://www.qwencloud.com/pricing/token-plan) ·
[Kimi](https://www.kimi.com/membership/pricing).

Vous pouvez d’abord essayer les applications de bureau des fournisseurs :
[Claude Desktop](https://claude.ai/download) ·
[ChatGPT Desktop](https://openai.com/chatgpt/download) ·
[Qwen Desktop](https://chat.qwen.ai) ·
[Kimi Desktop](https://kimi.ai/).

## 3. Modules de formation

La formation est proposée séparément, en trois modules, tous dispensés **sur site** par un formateur. Dans les cabinets d’un ou deux avocats, le formateur travaille directement sur vos dossiers en cours, dans le cadre d’un accord de confidentialité ; dans les cabinets plus importants, la formation débute par des sessions en groupe avec des exemples traités.

| Module | Format | Europe de l’Ouest (HT) \* | Europe de l’Est (HT) \* |
| --- | --- | --- | --- |
| **Formation de base IA** | 1 jour sur site | 2 200 € | 1 500 € |
| **Formation experte IA** | 1 jour sur site, prolongeable par journée | 2 500 € par jour | 1 800 € par jour |
| **Module spécial OSINT** | sur site, à la journée | 2 500 € par jour | 1 800 € par jour |

\* Frais de déplacement et d’hébergement en sus.

**Remarque sur la formation experte IA.** Des journées supplémentaires peuvent être réservées pour les workflows multi-modèles avancés, la rédaction contradictoire et les instructions d’IA propres au cabinet.
