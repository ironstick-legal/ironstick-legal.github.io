Manuel - Démarrage rapide

Démarrage rapide — de l’installation à vos premiers clients en six étapes.

1. Installer IRONSTICK

Téléchargez le programme d'installation et installez IRONSTICK sur votre ordinateur Windows en quelques clics. Choisissez la langue du programme d'installation, le dossier de destination et la création éventuelle d'un raccourci sur le bureau ; le programme est ensuite installé. Si IRONSTICK est déjà installé, installez la nouvelle version par-dessus — vos données restent là où elles sont.

Ce que vous pouvez faire ici

Programme d'installation

  • Langue du programme d'installation. Choisissez la langue du programme d'installation et confirmez avec OK.
  • Dossier de destination. Le dossier proposé est C:\Program Files\IRONSTICK. Conservez-le, ou choisissez-en un autre avec Parcourir….
  • Raccourci sur le bureau. Laissez la case cochée si vous souhaitez une icône IRONSTICK sur le bureau.
  • Installer. Le récapitulatif affiche encore une fois le dossier et le raccourci ; Installer lance l'installation, et une barre de progression en suit le déroulement.

Premier démarrage

  • Clé de licence. Au premier démarrage, IRONSTICK vous demande votre clé de licence. Saisissez-la à partir de votre document de licence, ou collez-la.
  • Code de sécurité. Après une clé de licence valide, un code QR s'affiche. Scannez-le avec une application d'authentification sur votre téléphone. Dès lors, IRONSTICK n'affiche vos données qu'après la saisie du code à six chiffres de cette application.
  • Nouveau téléphone. Si vous changez de téléphone ou le perdez, saisissez à nouveau la clé de licence sur l'écran de démarrage ; le code QR réapparaît afin que vous puissiez configurer le nouveau téléphone.

2. Licence, utilisateur et langue

Ouvrez la configuration avec l'icône en forme de roue dentée dans la barre supérieure. Vous y saisissez ou renouvelez votre clé de licence, remplissez votre fiche utilisateur et choisissez la langue de l'interface et du dialogue avec l'IA. Prenez une minute pour la fiche utilisateur : vos données sont utilisées dans les courriers, les actes de procédure et la demande de licence.

  1. Clé de licence. Le lien Clé de licence sous la ligne de version ouvre la fenêtre de licence. Saisissez ou collez la clé et cliquez sur Activer. Demander une clé de licence vérifie que votre fiche utilisateur est complète et prépare le texte de la demande avec objet et destinataire, chacun avec un bouton de copie.
  2. Utilisateur. Ouvre votre fiche utilisateur. Le numéro à côté du titre identifie votre installation ; le petit symbole le copie.
  3. Champs issus de la licence. L'entreprise, la civilité, le prénom et le nom proviennent de votre clé de licence et sont verrouillés (cadenas). Remplissez les autres champs : fonction, adresse, pays, téléphone, mobile, e-mail, date de naissance et les applications de messagerie que vous utilisez.
  4. Langue. La langue de l'interface et du dialogue avec l'IA. Après Enregistrer, chaque écran passe immédiatement dans la nouvelle langue.

3. Configuration de l'IA

La configuration de l'IA contient les clés d'accès (clés API) des services d'IA que IRONSTICK peut utiliser. Il en existe deux sortes : des services gratuits qui n'effectuent que des tâches d'arrière-plan, et les services pour les fonctions d'IA complètes du chat intégré. Vous avez besoin d'un compte auprès du service concerné ; les liens sous chaque champ mènent à ses pages d'inscription, de conditions d'utilisation et de confidentialité.

  1. Configuration de l'IA. Ouvre la fiche avec tous les services d'IA.
  2. Services gratuits pour les tâches d'arrière-plan. Utilisés uniquement pour les travaux d'arrière-plan tels que la priorisation des e-mails, le moniteur de données, le briefing quotidien et le rapport de situation. Cliquez sur le lien sous le champ pour créer directement un compte auprès du fournisseur et y générer une clé API. Collez cette clé API dans le champ et cliquez sur Enregistrer. L'interrupteur à côté du service active ou désactive ce service pour ces activités — même si sa clé API reste enregistrée. L'indication sous chaque service précise les conditions du fournisseur auxquelles il prend en charge vos tâches d'arrière-plan.
  3. Services d'IA pour le chat intégré. Cliquez sur le lien sous le champ pour créer directement un compte auprès du fournisseur et y générer une clé API. Collez la clé API dans le champ et cliquez sur Enregistrer. Une recharge d'au moins 20 dollars/euros par fournisseur est recommandée. L'idéal est d'enregistrer au moins deux fournisseurs : si plusieurs services sont enregistrés, IRONSTICK les utilise automatiquement dans l'ordre fixe indiqué par les numéros, le moins cher en premier ; le suivant prend ainsi le relais sans accroc, et votre travail se poursuit sans interruption.

4. Votre signature

Votre signature est enregistrée une seule fois dans la configuration. IRONSTICK la place là où vous signez des documents : dans l'aperçu avant impression du traitement de texte et sur les tampons des annexes. Vous pouvez la dessiner avec la souris ou sur un écran tactile, ou téléverser un scan de votre signature.

  1. Signatures. Ouvre la fiche de signature.
  2. Champ de signature. Dessinez votre signature avec la souris ou le doigt. Effacer le champ de signature permet de recommencer ; Téléverser une image (JPG/PNG) prend à la place une signature scannée ; Supprimer retire la signature enregistrée ; Enregistrer la mémorise. La coche verte et le petit aperçu montrent la signature actuellement enregistrée.

5. Modèle d'en-tête

Téléversez une fois l'en-tête de votre cabinet sous forme de PDF A4. IRONSTICK place vos actes de procédure sur cet en-tête, le texte commençant en dessous de l'en-tête. Dans le traitement de texte, vous activez ou désactivez l'en-tête pour chaque document.

  1. Modèle d'en-tête. Ouvre la fiche du modèle.
  2. Téléverser le modèle. Choisissez le PDF A4 avec votre en-tête. Tant qu'aucun modèle n'est enregistré, la fiche l'indique.

6. Importer vos clients

Vous n'avez pas à saisir vos clients existants un par un. Exportez-les depuis votre programme précédent ou votre carnet d'adresses sous forme de fichier CSV ou vCard et faites glisser ce fichier dans la fenêtre d'importation. Si vous n'avez pas encore utilisé de logiciel de gestion des clients, une exportation de votre logiciel de facturation constitue souvent une bonne source pour l'importation. Pour ajouter un client manuellement, utilisez Nouveau client.

  1. Importer un client. Ouvre la fenêtre d'importation. Faites glisser un fichier CSV ou vCard (.vcf) sur la zone de dépôt. Enregistrez d'abord les classeurs Excel au format CSV. Pour un fichier CSV, une seconde fenêtre liste chaque colonne avec une valeur d'exemple et le champ dans lequel elle va ; l'attribution est préremplie et vous pouvez modifier chaque champ. Au moins une colonne doit être attribuée au nom. Si le fichier contient un seul contact, le formulaire Nouveau client s'ouvre prérempli ; s'il en contient plusieurs, vous sélectionnez dans une liste les contacts à importer — les clients déjà existants ne sont pas sélectionnés.
  2. Nouveau client. Ouvre un formulaire client vide pour un client que vous saisissez à la main.
Et voilà, vous êtes prêt à saisir vos dossiers dans IRONSTICK. Que vous saisissiez tous vos dossiers existants dans IRONSTICK ou que vous commenciez simplement à travailler avec IRONSTICK sur vos nouveaux dossiers, c'est à vous de décider. En pratique, un mélange s'est révélé la meilleure voie : saisissez à la main quelques dossiers existants importants qui ont un besoin urgent du soutien d'IRONSTICK, et traitez en même temps tous les nouveaux dossiers directement dans IRONSTICK.
