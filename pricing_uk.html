IRONSTICK — Ціни

Модульне ліцензування: ви платите лише за те, чим ваша юридична фірма справді користується, — і будь-коли можете розширити або скоротити обсяг.

Усі ціни вказано без ПДВ. Ліцензії оплачуються щомісяця; навчальні модулі — разові послуги з виїздом до клієнта. Призначення окремих компонентів описано в супровідному комерційному документі IRONSTICK.

2. Акаунти в провайдерів ШІ

Рекомендовано для роботи IRONSTICK: API-акаунт в Anthropic (console.anthropic.com). Він працює як передплачений рахунок, який ви поповнюєте за потреби, і забезпечує базові функції ШІ в IRONSTICK. IRONSTICK показує в застосунку помітне попередження, щойно баланс налаштованого провайдера вичерпано. З Bridge ці витрати на API істотно зменшуються — усі ресурсомісткі запити тоді йдуть через підписку, а не через API-акаунт.

Підписки в Anthropic, OpenAI, Qwen і Kimi не обов’язкові для роботи IRONSTICK, але стають обов’язковими для роботи відповідного Bridge. Тарифи підписок: Anthropic · OpenAI · Qwen · Kimi.

Настільні застосунки можна випробувати вже зараз — завантаження: Claude Desktop · ChatGPT Desktop · Qwen Desktop · Kimi Desktop.

3. Навчальні модулі
