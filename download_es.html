Aplicación cliente

Puesto de trabajo Windows

La aplicación cliente y los Bridges se ejecutan en el mismo equipo Windows con una única clave de licencia IRONSTICK — los Bridges no necesitan una clave propia. Además se conecta una IA (véase Conexión de la IA).

IRONSTICK Client-App

La aplicación principal para el puesto de trabajo: casos, clientes, plazos, documentos, trabajo probatorio y el chat con IA — todo en local en su equipo Windows.

Bridges (MCP-Server)

Conectores que enlazan de forma segura los escritorios de IA externos con su Client-App a través del MCP-Server — la IA trabaja directamente sobre el expediente. Cada Bridge requiere una licencia de Client-App.

Conexión de la IA

Con una clave API de IA están disponibles todas las funciones de IA de la aplicación cliente. Los importes para activar las claves API varían según el proveedor, pero oscilan entre una recarga mínima de 1 $ y 5 $ para la activación inicial. Se recomienda utilizar al menos dos claves API para aumentar la tolerancia a fallos. La facturación se realiza de todos modos según el uso; por lo tanto, las claves API no utilizadas no generan costes. La aplicación cliente está programada para evitar costes en la medida de lo posible y activar las claves API solo cuando sea necesario. Tras iniciar sesión, el usuario tiene acceso a través de la pantalla de configuración y puede solicitar allí las claves API directamente a los proveedores (los enlaces directos están incluidos).

Las aplicaciones de escritorio de IA también pueden usarse para pruebas sin suscripción. Los costes mensuales de suscripción en los proveedores comienzan en unos 20 $ al mes. Si nota que su suscripción con un proveedor no es suficiente, los proveedores ofrecen ampliaciones. Si ya existe una suscripción, puede seguir utilizándose sin más con la configuración existente — el usuario no tiene que cambiar nada. Hay dos formas de usar aplicaciones de escritorio de IA existentes: a) exportando archivos de instrucciones de IA (con muchas pérdidas) o b) a través del Bridge (servidor MCP). Una vez que el usuario se ha acostumbrado a su aplicación de escritorio de IA, se recomienda, por motivos de tolerancia a fallos, instalar una segunda aplicación de escritorio de otro proveedor. Los enlaces de descarga están disponibles directamente en la pantalla de configuración.

Servidor y puesto de escaneo

El servidor IRONSTICK es un archivo SPK preempaquetado que se instala en su NAS Synology con 3 clics de ratón. Todo lo que necesita es un NAS Synology; los modelos económicos parten de unos 180 €. También aquí: ningún esfuerzo de instalación. Conéctelo y déjelo funcionar.

IRONSTICK Server

Funciona en un NAS Synology corriente y comparte casos, documentos y plazos entre varios puestos de trabajo — almacenamiento central y cifrado, con autorreparación y copias de seguridad. A partir de un mínimo de dos licencias de Client-App.

Orden de instalación

  1. Instale la primera Client-App y actívela con la clave de licencia.
  2. Instale la(s) Bridge(s) en el mismo equipo.
  3. Instale el Server en el NAS (Synology).
  4. Instale la Scan-App en el puesto de escaneo.
  5. Instale y active las demás Client-Apps.

Reglas de licencia

  • Cada licencia está a nombre de un solo usuario (una persona).
  • No hay licencia de Server sin al menos dos licencias de Client-App.
  • No hay licencia de Scan-App sin al menos una licencia de Server.
  • No hay licencia de Bridge sin licencia de Client-App.

Dónde se introduce la clave de licencia

Client-App

La clave se introduce al iniciar el programa en la ventana de licencia (modificable después en la configuración). Al mismo tiempo, activa las Bridges — estas no necesitan una clave propia.

IRONSTICK Server

La clave del Server se registra durante la configuración del Server.

La clave se introduce al iniciar la Scan-App en la ventana de licencia.

Prueba gratuita

Para la Client-App existe, a petición, una clave de licencia gratuita durante un mes, para conocer el producto con calma. Para Server y Scan-App no hay período de prueba.

Renovación de la licencia

¿Qué ocurre cuando caduca la licencia? Aproximadamente 10 días antes del vencimiento de su licencia, la aplicación cliente le avisa (si tiene en funcionamiento el servidor IRONSTICK, verá un resumen de licencias de todos los clientes conectados). A continuación, puede pedir muy fácilmente las claves de licencia necesarias por correo electrónico o WhatsApp. Su solicitud se verifica con los datos existentes y se espera la recepción del pago. En cuanto se haya recibido el pago, recibirá la nueva clave de licencia por correo electrónico / WhatsApp. Se trata de una cadena de caracteres que solo tiene que copiar en su aplicación cliente (copiar y pegar).
