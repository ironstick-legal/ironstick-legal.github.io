Conectarea IA

Cu o cheie API IA, toate funcțiile IA ale aplicației client sunt disponibile. Sumele pentru activarea cheilor API diferă de la un furnizor la altul, dar se situează între o reîncărcare minimă de 1 $ și 5 $ pentru activarea inițială. Se recomandă utilizarea a cel puțin două chei API pentru a crește siguranța în caz de defecțiune. Facturarea se face oricum pe bază de utilizare; prin urmare, cheile API neutilizate nu generează costuri. Aplicația client este programată astfel încât să evite pe cât posibil costurile și să activeze cheile API doar la nevoie. După autentificare, utilizatorul are acces prin ecranul de configurare și poate solicita cheile API direct de la furnizori (linkurile directe sunt incluse).

Aplicațiile desktop IA pot fi folosite pentru testare și fără abonament. Costurile lunare de abonament la furnizori încep de la aproximativ 20 $ pe lună. Dacă observați că abonamentul la un furnizor nu vă ajunge, furnizorii oferă extinderi. Dacă există deja un abonament, acesta poate fi folosit în continuare cu configurația existentă — utilizatorul nu trebuie să schimbe nimic. Există două moduri de a folosi aplicațiile desktop IA existente: a) prin exportul fișierelor de instrucțiuni IA (cu pierderi mari) sau b) prin Bridge (server MCP). După ce utilizatorul s-a obișnuit cu aplicația sa desktop IA, se recomandă, din motive de siguranță, instalarea unei a doua aplicații desktop de la un alt furnizor. Linkurile de descărcare sunt disponibile direct în ecranul de configurare.

Serverul și stația de scanare

Serverul IRONSTICK este un fișier SPK preambalat, care se instalează pe NAS-ul dumneavoastră Synology din 3 clicuri de mouse. Tot ce vă trebuie este un NAS Synology; modelele accesibile pornesc de la aproximativ 180 €. Și aici: niciun efort de instalare. Îl conectați și îl lăsați să funcționeze.

IRONSTICK Server

Rulează pe un NAS Synology obișnuit și partajează dosarele, documentele și termenele între mai multe posturi de lucru — stocare centralizată, criptată, cu autoreparare și copii de siguranță. De la minimum două licențe Client-App.

Ordinea de instalare

  1. Instalați prima Client-App și activați-o cu cheia de licență.
  2. Instalați Bridge(s) pe același calculator.
  3. Instalați Server-ul pe NAS (Synology).
  4. Instalați Scan-App la postul de scanare.
  5. Instalați și activați celelalte Client-App-uri.

Reguli de licențiere

  • Fiecare licență este emisă pe exact un utilizator (o persoană).
  • O licență Server nu se acordă fără cel puțin două licențe Client-App.
  • O licență Scan-App nu se acordă fără cel puțin o licență Server.
  • O licență Bridge nu se acordă fără o licență Client-App.

Reînnoirea licenței

Ce se întâmplă când expiră licența?
