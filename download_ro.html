Aplicația client

Stație de lucru Windows

Aplicația client și Bridge-urile rulează pe aceeași stație de lucru Windows sub o singură cheie de licență IRONSTICK. Fiecare Bridge se licențiază separat și se deblochează în cheia de licență a aplicației client, deci nu este nevoie de o cheie separată pentru Bridge. În plus, se conectează un furnizor de IA.

Conectarea IA

Cu o cheie API IA, toate funcțiile IA ale aplicației client sunt disponibile. Se recomandă o reîncărcare de cel puțin 20 de dolari/euro per furnizor. Facturarea se face pe bază de utilizare, deci o cheie neutilizată nu costă nimic. Aplicația client este concepută să evite costurile și apelează un API plătit doar atunci când o sarcină o cere. Cheile API se introduc în ecranul de configurare, care trimite direct la paginile de chei și de facturare ale fiecărui furnizor.

Aplicațiile desktop IA pot fi încercate și fără abonament. Abonamentul este taxa lunară fixă a furnizorului, iar furnizorii oferă extinderi pentru capacitate suplimentară. Un abonament existent poate fi folosit ca atare, fără a-i modifica configurația. Aplicațiile desktop se conectează în două moduri: prin Bridge (server MCP) sau prin exportul fișierelor de instrucțiuni IA. Linkurile de descărcare se află în ecranul de configurare.

Serverul și stația de scanare

IRONSTICK SERVER, serverul de cabinet, se livrează ca pachet Synology (SPK) gata de instalare și se instalează pe NAS-ul dumneavoastră din trei clicuri. Tot ce vă trebuie este un NAS Synology obișnuit, de exemplu un DS223j, de la aproximativ 180 €. După instalare rulează în fundal; administrarea se face într-un browser.

IRONSTICK SERVER

Rulează pe un NAS Synology obișnuit și leagă mai multe posturi de lucru: dosare partajate, o bibliotecă de legi la nivelul cabinetului și preluare centrală a scanărilor, pe propriul NAS. Se reconstruiește singur din posturile de lucru și afișează ultima copie de siguranță a fiecărui utilizator. Serverul funcționează în întregime în rețeaua cabinetului dumneavoastră, fără cloud și fără trafic IA. Disponibil de la două licențe ale aplicației client.

Ordinea de instalare

  1. Instalați prima aplicație client și activați-o cu cheia dumneavoastră de licență.
  2. Instalați Bridge-urile pe aceeași stație de lucru.
  3. Instalați IRONSTICK SERVER pe NAS-ul Synology.
  4. Instalați Central Scan App la postul de scanare.
  5. Instalați și activați celelalte aplicații client.

Reguli de licențiere

  • Fiecare licență este emisă pe un utilizator nominal (o persoană).
  • O licență IRONSTICK SERVER necesită cel puțin două licențe ale aplicației client.
  • O licență Central Scan App necesită cel puțin o licență IRONSTICK SERVER.
  • O licență Bridge necesită o licență a aplicației client; ea se deblochează în cheia aplicației client.

Cu aproximativ 10 zile înainte de expirarea unei licențe, aplicația client afișează un memento; cu IRONSTICK SERVER, pagina de administrare afișează și o prezentare a licenței aplicației client a fiecărui utilizator. Comandați reînnoirea prin e-mail sau WhatsApp. După ce comanda a fost verificată în raport cu datele dumneavoastră de client și plata a fost primită, primiți noua cheie de licență prin e-mail sau WhatsApp și o lipiți în aplicația client.
