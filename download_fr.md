## Connexion de l'IA

![Le poste de travail Windows avec une licence IRONSTICK pour le client et le serveur MCP, plus, en externe, soit une clé API d'IA, soit une application de bureau d'IA avec abonnement.](https://www.ironstick.legal/img/dl_client.png)

Avec une **clé API d'IA**, toutes les fonctions d'IA de l'application client sont disponibles. Les montants pour activer les clés API varient selon les fournisseurs, mais se situent entre un rechargement minimum de 1 $ et 5 $ pour l'activation initiale. Il est recommandé d'utiliser au moins **deux clés API** afin d'améliorer la tolérance aux pannes. La facturation se fait de toute façon à l'usage ; les clés API non utilisées n'entraînent donc aucun coût. L'application client est programmée pour éviter autant que possible les coûts et n'activer les clés API qu'en cas de besoin. Après la connexion, l'utilisateur y a accès via l'écran de configuration et peut y demander les clés API directement auprès des fournisseurs (les liens directs sont fournis).

Les **applications de bureau d'IA** peuvent aussi être utilisées pour des tests sans abonnement. Les coûts d'abonnement mensuels chez les fournisseurs commencent à environ 20 $ par mois. Si vous constatez que votre abonnement chez un fournisseur ne suffit pas, les fournisseurs proposent des extensions. Si un abonnement existe déjà, il peut simplement être conservé avec la configuration existante — l'utilisateur n'a rien à changer. Il existe deux façons d'utiliser des applications de bureau d'IA existantes : a) en exportant des fichiers d'instructions d'IA (très dégradé) ou b) via le Bridge (serveur MCP). Une fois que l'utilisateur s'est habitué à son application de bureau d'IA, il est recommandé, pour des raisons de tolérance aux pannes, d'installer une deuxième application de bureau d'un autre fournisseur. Les liens de téléchargement sont disponibles directement dans l'écran de configuration.

## Ordre d'installation

1. Installer la première **Client-App** et l'activer avec la clé de licence.
2. Installer la ou les **Bridge(s)** sur le même ordinateur.
3. Installer le **Server** sur le NAS (Synology).
4. Installer la **Scan-App** sur le poste de numérisation.
5. Installer et activer les **autres Client-Apps**.

## Règles de licence

- Chaque licence est établie au nom d'**un seul utilisateur** (une personne).
- Une **licence Server** n'est pas délivrée sans au moins **deux licences Client-App**.
- Une **licence Scan-App** n'est pas délivrée sans au moins **une licence Server**.
- Une **licence Bridge** n'est pas délivrée sans **licence Client-App**.

## Où saisir la clé de licence

### Client-App

La clé se saisit au démarrage du programme dans la fenêtre de licence (modifiable ultérieurement dans la configuration). Elle débloque en même temps les **Bridges** — celles-ci n'ont pas besoin de leur propre clé.

### IRONSTICK Server

La clé Server s'enregistre lors de la configuration du Server.

### Central Scan-App

La clé se saisit au démarrage de la Scan-App dans la fenêtre de licence.

## Essayer gratuitement

Pour la **Client-App**, une **clé de licence gratuite d'un mois** est disponible sur demande, afin de découvrir le produit en toute tranquillité. Pour le **Server** et la **Scan-App**, il n'existe aucune période d'essai.

## Renouvellement de la licence

Que se passe-t-il lorsque la licence expire ? Environ **10 jours avant l'expiration** de votre licence, l'application client vous avertit (si vous exploitez le serveur IRONSTICK, vous voyez un aperçu des licences de tous les clients connectés). Vous pouvez alors commander très simplement les clés de licence nécessaires par e-mail ou WhatsApp. Votre demande est vérifiée par rapport aux données existantes et le paiement est attendu. Dès que le paiement a été reçu, vous recevez la nouvelle clé de licence par e-mail / WhatsApp. Il s'agit d'une chaîne de caractères qu'il vous suffit de copier dans votre application client (copier-coller).
