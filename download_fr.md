## Application client

### Poste de travail Windows

L'application client et les Bridges s'exécutent sur le même poste de travail Windows sous **une seule clé de licence IRONSTICK**. Chaque Bridge fait l'objet d'une licence distincte et est débloqué dans la clé de licence de votre application client : aucune clé Bridge distincte n'est donc nécessaire. Un fournisseur d'IA est en outre connecté.

### Application client IRONSTICK

L'application principale pour le poste de travail : dossiers, clients, délais, documents, travail sur les preuves et le [chat IA](https://www.ironstick.legal/ki_fr.html) — le tout stocké en local sur votre poste de travail Windows.

### Bridges (serveurs MCP)

Des connecteurs qui relient les applications d'IA de bureau à votre application client via un serveur MCP local, afin que l'IA puisse [travailler directement sur le dossier](https://www.ironstick.legal/ki_fr.html). Chaque Bridge nécessite une licence d'application client.

## Connexion de l'IA

![Poste de travail Windows avec une licence IRONSTICK couvrant l'application client et le serveur MCP, relié soit à une clé API d'IA, soit à une application de bureau d'IA avec abonnement.](https://www.ironstick.legal/img/dl_client.png)

Avec une **clé API d'IA**, toutes les fonctions d'IA de l'application client sont disponibles. Un rechargement d'au moins 20 dollars/euros par fournisseur est recommandé. La facturation se fait à l'usage : une clé inutilisée ne coûte rien. L'application client est conçue pour éviter les coûts et n'appelle une API payante que lorsqu'une tâche l'exige. Les clés API se saisissent dans l'[écran de configuration](https://www.ironstick.legal/manualquickstart_fr.html#q3), qui renvoie directement aux pages de clés et de facturation de chaque fournisseur.

Les **applications de bureau d'IA** peuvent aussi être essayées sans abonnement. Un abonnement est le forfait mensuel fixe du fournisseur, et les fournisseurs proposent des extensions pour une capacité supplémentaire. Un abonnement existant peut être utilisé tel quel, sans modifier sa configuration. Les applications de bureau se connectent de deux façons : via le [Bridge (serveur MCP)](https://www.ironstick.legal/manualbridge_fr.html), ou en exportant des fichiers d'instructions d'IA. Les liens de téléchargement figurent dans l'[écran de configuration](https://www.ironstick.legal/manualironstick_fr.html#s2).

## Serveur et poste de numérisation

![IRONSTICK SERVER : votre NAS Synology plus une licence IRONSTICK SERVER.](https://www.ironstick.legal/img/dl_server.png)

IRONSTICK SERVER, le serveur de cabinet, est fourni sous forme de paquet Synology prêt à l'emploi (SPK) et s'installe sur votre NAS en trois clics. Il vous suffit d'un NAS Synology ordinaire, par exemple un DS223j à partir d'environ 180 €. Une fois installé, il tourne en arrière-plan ; l'administration se fait dans un navigateur.

### IRONSTICK SERVER

Fonctionne sur un NAS Synology ordinaire et relie plusieurs postes de travail : dossiers partagés, bibliothèque de lois à l'échelle du cabinet et réception centralisée des numérisations sur votre propre NAS. Il se reconstruit à partir des postes de travail et affiche la dernière sauvegarde de chaque utilisateur. Le serveur fonctionne entièrement au sein du réseau de votre cabinet, sans aucun cloud et sans trafic d'IA. Disponible à partir de deux licences d'application client.

[Télécharger](https://github.com/ironstick-legal/ironstick-legal.github.io/releases/download/v1.0.7/ironstick-server-synology-1.0.0.spk)

### Central Scan App

Le poste de saisie au scanner : le courrier entrant et les documents sont numérisés de manière centralisée, affectés aux dossiers et injectés automatiquement. Nécessite IRONSTICK SERVER.

[Télécharger](https://github.com/ironstick-legal/ironstick-legal.github.io/releases/download/v1.0.7/ironstick-centralscan-setup-1.0.3.exe)

## Ordre d'installation

1. [Installer](https://www.ironstick.legal/manualquickstart_fr.html#q1) la première **application client** et l'[activer avec votre clé de licence](https://www.ironstick.legal/manualquickstart_fr.html#q2).
2. Installer le ou les [**Bridge(s)**](https://www.ironstick.legal/manualbridge_fr.html) sur le même poste de travail.
3. Installer **IRONSTICK SERVER** sur le NAS Synology.
4. Installer la **Central Scan App** sur le poste de numérisation.
5. Installer et activer les **autres applications client**.

## Règles de licence

- Chaque licence est établie au nom d'**un utilisateur nommément désigné** (une personne).
- Une **licence IRONSTICK SERVER** exige au moins **deux licences d'application client**.
- Une **licence Central Scan App** exige au moins **une licence IRONSTICK SERVER**.
- Une **licence Bridge** exige une **licence d'application client** ; elle est débloquée dans la clé de l'application client.

## Saisie de la clé de licence

### Application client

Saisissez la clé dans la fenêtre de licence au démarrage de l'application client ; vous pourrez la modifier ensuite dans la [configuration](https://www.ironstick.legal/manualquickstart_fr.html#q2). La même clé active vos **Bridges** sous licence ; il n'existe pas de clé Bridge distincte.

### IRONSTICK SERVER

La clé IRONSTICK SERVER se saisit lors de la configuration du serveur.

### Central Scan App

Saisissez la clé dans la fenêtre de licence au démarrage de la Central Scan App.

## Essayer gratuitement

Pour l'**application client**, vous recevez sur demande une **licence d'essai gratuite de 30 jours**, afin que vous puissiez évaluer le produit à votre rythme. Prenez par exemple un ancien dossier, saisissez-le pas à pas dans IRONSTICK et observez l'écart entre vos saisies et appréciations et celles d'IRONSTICK. Vous obtenez ainsi une comparaison directe.

## Renouvellement de licence

Environ **10 jours avant l'expiration** d'une licence, l'application client affiche un rappel ; avec IRONSTICK SERVER, la page d'administration affiche aussi un aperçu de la licence d'application client de chaque utilisateur. Commandez le renouvellement par e-mail ou WhatsApp. Une fois votre commande vérifiée par rapport à vos données client et le paiement reçu, vous recevez la nouvelle clé de licence par e-mail ou WhatsApp et vous la collez dans l'application client.
