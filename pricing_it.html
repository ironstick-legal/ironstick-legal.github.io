Prezzi

Licenze modulari: paghi solo ciò che il tuo studio utilizza effettivamente — e scali in qualsiasi momento verso l’alto o verso il basso.

Tutti i prezzi sono netti (IVA esclusa). Le licenze sono fatturate mensilmente; i moduli di formazione sono servizi una tantum in sede. Ogni componente è descritto nel compendio dell’App client e nel compendio del Bridge.

2. Account presso i fornitori di IA

Consigliato: un account API presso Anthropic (console.anthropic.com). L’IA integrata di IRONSTICK funziona con una chiave API di Anthropic, OpenAI, Qwen o Kimi; si consiglia una chiave Anthropic perché alimenta anche funzioni come la ricerca di link web con l’IA. Un account API è un conto prepagato che ricarichi secondo necessità. IRONSTICK ti avvisa nell’app non appena il credito di un fornitore configurato è esaurito. Con un Bridge, il lavoro che svolgi con la tua IA desktop passa sul tuo abbonamento anziché sull’account API: un abbonamento è la tariffa mensile fissa del fornitore, mentre l’accesso API è fatturato dal fornitore in base all’uso. Le attività in background dell’App client usano le chiavi API oppure, se configurati, i livelli gratuiti di Groq, OpenRouter e Mistral.

Un abbonamento presso Anthropic, OpenAI, Qwen o Kimi è facoltativo per IRONSTICK stesso; l’App client da sola richiede solo una chiave API; il Bridge corrispondente funziona attraverso l’app desktop di quel fornitore e il tuo account presso di esso. Piani di abbonamento: Anthropic · OpenAI · Qwen · Kimi.

Puoi provare prima le app desktop dei fornitori: Claude Desktop · ChatGPT Desktop · Qwen Desktop · Kimi Desktop.

3. Moduli di formazione

La formazione è offerta separatamente, in tre moduli, tutti svolti in sede da un formatore. Negli studi con uno o due avvocati il formatore lavora direttamente sui tuoi fascicoli in corso, vincolato da un accordo di riservatezza; negli studi più grandi la formazione parte da sessioni di gruppo ed esempi svolti.
